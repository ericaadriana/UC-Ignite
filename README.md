# IGNITE — UC Global Entrepreneurship Week 2026

Event website for IGNITE, 18–20 November 2026 at Universitas Ciputra.
Built with [Astro](https://astro.build) and Tailwind CSS, deployed on Vercel.

## Edit the content

Event details (dates, speakers, ticket prices, registration link, Instagram) live in
`src/data/event.ts`. Each page section is a component in `src/components/`.

## Run locally

```bash
npm install
npm run dev
```

`npm run build` writes the static site to `dist/`. Vercel builds it on every push.
